## 🔹 ¿Qué es `?

Es una forma **súper visual** de definir el layout de un Grid, usando **nombres de áreas** en lugar de coordenadas.  
Te permite “dibujar” con texto dónde va cada parte: `header`, `sidebar`, `main`, `footer`, etc.

---

## 🔹 Ejemplo paso a paso

### 1. Definir el contenedor

```css
.container {
  display: grid;
  grid-template-columns: 150px 1fr 1fr;   /* 3 columnas: 150px + 2 iguales */
  grid-template-rows: 80px 1fr 60px;      /* 3 filas: header, contenido, footer */
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "footer footer footer";
  gap: 10px; /* espacio entre áreas */
  height: 100vh;
}
```

👉 Esto crea una rejilla de **3 columnas × 3 filas** y le dice:

- Fila 1 → todo es `header`.
- Fila 2 → primera columna `sidebar`, segunda y tercera `main`.
- Fila 3 → todo es `footer`.

---

### 2. Asignar las áreas a los ítems

```css
.header {
  grid-area: header;
  background: lightblue;
}

.sidebar {
  grid-area: sidebar;
  background: lightgreen;
}

.main {
  grid-area: main;
  background: lightcoral;
}

.footer {
  grid-area: footer;
  background: lightgoldenrodyellow;
}
```

---

### 3. El HTML

```html
<div class="container">
  <div class="header">HEADER</div>
  <div class="sidebar">SIDEBAR</div>
  <div class="main">MAIN CONTENT</div>
  <div class="footer">FOOTER</div>
</div>
```

---

## 🔎 Resultado visual

- **Header** arriba ocupando todo el ancho.
- **Sidebar** a la izquierda en la segunda fila.
- **Main** al lado ocupando 2 columnas.
- **Footer** abajo ocupando todo el ancho.

Es como “pintar” el layout con nombres en vez de números.

---

✅ Ventaja: `grid-template-areas` es **muy legible** y hace que el HTML no dependa del orden de los elementos: podés reordenar solo con CSS.
