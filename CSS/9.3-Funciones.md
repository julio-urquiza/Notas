## 🔹 Tipos de funciones en CSS

### 1️⃣ Funciones de **color**

- Permiten definir colores o modificarlos:

```css
color: rgb(255, 0, 0);      /* rojo puro */
color: rgba(255, 0, 0, 0.5);/* rojo semitransparente */
color: hsl(120, 100%, 50%); /* verde */
color: hsla(120, 100%, 50%, 0.3); /* verde semitransparente */
```

- Otras funciones:

```css
color: lighten(#3498db, 20%);  /* Sass / Less */
color: darken(#3498db, 20%);
```

---

### 2️⃣ Funciones de **medidas y cálculos**

- `calc()` → permite **sumar, restar, multiplicar o dividir valores**:

```css
width: calc(100% - 20px);
font-size: calc(1em + 2vw);
```

---

### 3️⃣ Funciones de **transformaciones**

- `translate()`, `rotate()`, `scale()`, `skew()` → se usan en `transform`:

```css
div:hover {
  transform: translateX(50px) rotate(15deg) scale(1.2);
}
```

---

### 4️⃣ Funciones de **gradientes**

- Para fondos con degradado:

```css
background: linear-gradient(to right, red, yellow);
background: radial-gradient(circle, blue, white);
```

---

### 5️⃣ Funciones de **fuentes y tamaños**

- `min()`, `max()`, `clamp()` → muy útiles para layouts responsivos:

```css
font-size: clamp(14px, 2vw, 20px); /* mínimo 14px, máximo 20px */
width: min(500px, 80%);
width: max(200px, 50%);
```

---

### 6️⃣ Funciones de **URL / recursos**

- `url()` → para imágenes, fuentes, etc.

```css
background-image: url('fondo.jpg');
@font-face {
  font-family: 'MiFuente';
  src: url('mi-fuente.woff2') format('woff2');
}
```

---

## 🔹 Resumen rápido

- CSS tiene **funciones para colores, medidas, transformaciones, gradientes y recursos**.
- No ejecutan lógica como JS, pero **calculan valores dinámicamente**.
- Algunas funciones (`calc`, `clamp`) son muy poderosas para hacer **diseños responsivos** sin JavaScript.
