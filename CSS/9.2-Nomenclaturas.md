---

## 🔹 Tipos de selectores y nomenclaturas en CSS

### 1. **Clase (`.`)**

- Selecciona elementos por **clase**.
- Ejemplo:

```css
.card {
  background: lightblue;
}
```

- HTML: `<div class="card"></div>`

---

### 2. **ID (`#`)**

- Selecciona un **elemento único** por su `id`.
- Ejemplo:

```css
#header {
  background: red;
}
```

- HTML: `<div id="header"></div>`

---

### 3. **Elemento / Tag**

- Selecciona por el **nombre de la etiqueta HTML**.
- Ejemplo:

```css
p {
  font-size: 16px;
}
```

---

### 4. **Hijo directo (`>`)**

- Selecciona **solo hijos inmediatos** de un contenedor.
- Ejemplo:

```css
.grid > div {
  background: lightgreen;
}
```

- Solo los `div` que son hijos directos de `.grid` se verán afectados.

---

### 5. **Descendiente (espacio)**

- Selecciona **cualquier hijo, nieto, bisnieto, etc.**
- Ejemplo:

```css
.grid div {
  color: blue;
}
```

- Todos los `div` dentro de `.grid`, sin importar la profundidad.

---

### 6. **Pseudo-clases (`:`)**

- Para estados especiales o interacciones:

```css
a:hover { color: red; }
input:focus { border: 2px solid blue; }
```

---

### 7. **Pseudo-elementos (: :)**

- Para crear elementos virtuales o estilizar partes de un elemento:

```css
h1::after { content: " ⭐"; }
p::first-letter { font-size: 2em; }
```

---

### 8. **Atributo (`[attr]`)**

- Selecciona elementos según un atributo o valor:

```css
input[type="text"] { border: 1px solid gray; }
a[target="_blank"] { color: green; }
```

---

### 9. **Combinadores avanzados**

|Combinador|Qué hace|
|---|---|
|`+`|Selecciona el **hermano siguiente inmediato**|
|`~`|Selecciona **hermanos siguientes**|
|`,`|Combina varios selectores|

Ejemplo:

```css
h2 + p { margin-top: 0; }   /* primer párrafo después de h2 */
h2, h3 { font-weight: bold; } /* aplica a h2 y h3 */
```

---

✅ **Resumen rápido:**

- `.clase` → cualquier elemento con esa clase
- `#id` → elemento único con ese id
- `div`, `p` → por tipo de etiqueta
- `>` → hijos directos
- `espacio` → todos los descendientes
- `:` y `::` → pseudo-clases y pseudo-elementos
- `[attr]` → atributos
- `+`, `~`, `,` → combinadores avanzados

## 🔹 Selector de **atributos** `[attr]` en CSS

Se usa para seleccionar **elementos HTML según un atributo** que tengan, o según su valor.

### 1️⃣ Seleccionar por **atributo presente**

```css
input[required] {
  border: 2px solid red;
}
```

- Aplica **a todos los `input` que tengan el atributo `required`**, sin importar su valor.
- HTML:

```html
<input type="text" required>
<input type="text">
```

✅ Solo el primer input tendrá borde rojo.

---

### 2️⃣ Seleccionar por **atributo con valor específico**

```css
input[type="text"] {
  border: 1px solid gray;
}
```

- Aplica **solo a los inputs cuyo atributo `type` sea exactamente "text"**.
- HTML:

```html
<input type="text">  <!-- estilo aplicado -->
<input type="password">  <!-- no aplica -->
```

---

### 3️⃣ Seleccionar por **atributo que contiene palabra**

```css
a[target~="_blank"] {
  color: green;
}
```

- Aplica a enlaces cuyo `target` contenga la palabra `_blank`.
- Ejemplo HTML:

```html
<a href="..." target="_blank">Abrir en nueva pestaña</a>
<a href="..." target="_self">Misma pestaña</a>
```

✅ Solo el primero se pone verde.

---

### 🔹 Otros usos comunes

|Selector|Qué hace|
|---|---|
|`[attr^="valor"]`|Empieza con "valor"|
|`[attr$="valor"]`|Termina con "valor"|
|`[attr*="valor"]`|Contiene "valor" en cualquier parte|

Ejemplo:

```css
img[src$=".jpg"] { border: 1px solid black; }  /* todas las imágenes .jpg */
a[href^="https"] { color: blue; }              /* todos los enlaces https */
```

---

✅ **Resumen sencillo:**

- `[atributo]` → elemento que tiene ese atributo
- `[atributo="valor"]` → elemento con atributo exacto
- `[atributo^="valor"]` → atributo que empieza con ese valor
- `[atributo$="valor"]` → atributo que termina con ese valor
- `[atributo*="valor"]` → atributo que contiene ese valor
