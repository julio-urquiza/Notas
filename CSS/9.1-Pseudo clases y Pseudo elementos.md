## 🔹 Pseudo-clases comunes (lo que podríamos llamar “eventos CSS”)

Estas permiten aplicar estilos **cuando ocurre algo** con un elemento:

|Pseudo-clase|Qué hace / Cuándo se activa|
|---|---|
|`:hover`|Cuando el mouse pasa por encima del elemento|
|`:active`|Mientras el elemento está siendo presionado/clickeado|
|`:focus`|Cuando un elemento recibe foco (input, textarea, botón)|
|`:visited`|Cuando un enlace ha sido visitado por el usuario|
|`:link`|Cuando un enlace **no ha sido visitado**|
|`:checked`|Cuando un checkbox o radio está seleccionado|
|`:disabled`|Cuando un elemento está deshabilitado|
|`:enabled`|Cuando un elemento está habilitado|
|`:first-child`|Aplica al primer hijo dentro de un contenedor|
|`:last-child`|Aplica al último hijo dentro de un contenedor|
|`:nth-child(n)`|Aplica al hijo número `n` o según patrón|
|`:not(selector)`|Aplica a todos los elementos que **no** cumplan el selector|

---

## 🔹 Ejemplos prácticos

```css
/* Cambia color al pasar el mouse */
button:hover {
  background-color: red;
  color: white;
}

/* Input que cambia borde al recibir foco */
input:focus {
  border: 2px solid blue;
}

/* Checkbox marcado */
input[type="checkbox"]:checked + label {
  font-weight: bold;
}
```

## 🔹 Pseudo-elementos (para efectos visuales)

No son eventos, pero sirven para crear efectos “dinámicos”:

|Pseudo-elemento|Qué hace|
|---|---|
|`::before`|Inserta contenido antes del elemento|
|`::after`|Inserta contenido después del elemento|
|`::first-letter`|Aplica solo a la primera letra de un bloque de texto|
|`::first-line`|Aplica solo a la primera línea de un bloque de texto|

Ejemplo:

```css
h1::after {
  content: " ✅";
}
```

👉 Esto agrega un check al final de cada `<h1>` sin tocar el HTML.

---

### 🔹 Resumen

- **“Eventos” CSS** = pseudo-clases (`:hover`, `:focus`, `:active`, etc.)
- Permiten **reactividad visual sin JS**.
- Para eventos reales (clic, scroll, teclado) necesitás **JavaScript**.

---

|Pseudo-clase|Qué hace|Ejemplo CSS|Cómo se ve / efecto|
|---|---|---|---|
|`:hover`|Cuando el mouse pasa por encima|`button:hover { background: red; }`|El botón cambia de color al pasar el mouse|
|`:active`|Mientras el elemento está siendo presionado|`button:active { transform: scale(0.95); }`|Botón se achica momentáneamente al clic|
|`:focus`|Cuando un elemento recibe foco (input, textarea, botón)|`input:focus { border: 2px solid blue; }`|Borde azul alrededor del input al hacer clic o tab|
|`:visited`|Cuando un enlace ha sido visitado|`a:visited { color: purple; }`|Enlaces visitados cambian de color a morado|
|`:link`|Cuando un enlace **no ha sido visitado**|`a:link { color: blue; }`|Enlaces sin visitar son azules|
|`:checked`|Cuando un checkbox o radio está seleccionado|`input[type="checkbox"]:checked + label { font-weight: bold; }`|Texto de label se pone en negrita si el checkbox está marcado|
|`:disabled`|Cuando un elemento está deshabilitado|`button:disabled { opacity: 0.5; cursor: not-allowed; }`|Botón gris y no clickeable|
|`:enabled`|Cuando un elemento está habilitado|`input:enabled { background: white; }`|Input habilitado con fondo blanco|
|`:first-child`|Aplica al primer hijo de un contenedor|`p:first-child { color: green; }`|El primer párrafo de un div se vuelve verde|
|`:last-child`|Aplica al último hijo|`p:last-child { color: red; }`|Último párrafo se vuelve rojo|
|`:nth-child(n)`|Aplica al hijo número n|`li:nth-child(2) { font-weight: bold; }`|El segundo elemento de la lista en negrita|
|`:not(selector)`|Aplica a todos que no cumplan el selector|`div:not(.special) { background: lightgray; }`|Todos los divs que **no** tengan clase `.special` se ponen gris|

---

### 🔹 Pseudo-elementos (para efectos visuales)

|Pseudo-elemento|Qué hace|Ejemplo CSS|Cómo se ve|
|---|---|---|---|
|`::before`|Inserta contenido antes del elemento|`h1::before { content: "⭐"; }`|Estrella antes de cada `<h1>`|
|`::after`|Inserta contenido después del elemento|`h1::after { content: "✅"; }`|Check al final de cada `<h1>`|
|`::first-letter`|Aplica solo a la primera letra|`p::first-letter { font-size: 2em; color: red; }`|Primera letra del párrafo grande y roja|
|`::first-line`|Aplica solo a la primera línea|`p::first-line { font-weight: bold; }`|Primera línea del párrafo en negrita|

---

💡 **Tip práctico:**

- Las pseudo-clases sirven para **interacciones de usuario**.
- Los pseudo-elementos sirven para **añadir contenido o estilo extra** sin tocar el HTML.
- Combinando ambos, podés crear efectos muy vistosos solo con CSS.
