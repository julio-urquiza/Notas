## 🔹 1. Usando `flex-wrap`

Por defecto, los elementos flex intentan **quedarse en una sola línea** (`nowrap`). Para que se adapten a pantallas más chicas:

```css
.container {
  display: flex;
  flex-wrap: wrap; /* permite que los elementos bajen a la siguiente línea */
  gap: 10px;       /* espacio entre elementos */
}
```

---

## 🔹 2. Ajustando el tamaño de los elementos

Podés usar `flex` para que los elementos **crezcan o se encojan según el espacio**:

```css
.item {
  flex: 1 1 200px; /* flex-grow | flex-shrink | flex-basis */
  background: lightblue;
  padding: 20px;
  text-align: center;
}
```

- `flex: 1 1 200px` significa:
    - `1` → puede crecer si hay espacio extra
    - `1` → puede encoger si no hay suficiente espacio
    - `200px` → tamaño inicial mínimo de la caja

✅ Resultado: los elementos se **ajustan automáticamente** según el tamaño del contenedor.

---

## 🔹 3. Combinando Flex con Media Queries

Si querés tener control total según pantalla:

```css
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.item {
  flex: 1 1 200px;
}

@media (max-width: 768px) {
  .item {
    flex: 1 1 100%; /* en pantallas chicas, cada elemento ocupa toda la fila */
  }
}
```

- Pantallas grandes → varias columnas de 200px mínimo
- Pantallas pequeñas → cada elemento ocupa **100% del ancho**, quedando uno debajo del otro

---

## 🔹 4. Ejemplo completo en HTML + CSS

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>
```

```css
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.item {
  flex: 1 1 200px;
  background: lightblue;
  padding: 20px;
  text-align: center;
}
```

- Los elementos se **reorganizan automáticamente** al cambiar el tamaño de la ventana.

---

✅ **Resumen rápido:**

1. `flex-wrap: wrap` → permite que los elementos bajen a otra fila.
2. `flex: 1 1 tamaño` → define crecimiento y encogimiento flexible.
3. Media queries → control extra para ajustar tamaños según pantalla.
