## 🔹 ¿Qué es la herencia en CSS?

- La **herencia** significa que algunos estilos aplicados a un **elemento padre** se **transmiten automáticamente** a sus **hijos**.
- No todos los estilos se heredan; algunos **deben ser aplicados directamente**.

---

## 🔹 Propiedades que **sí se heredan** (ejemplos comunes)

|Propiedad|Qué hace|
|---|---|
|`color`|El color del texto|
|`font-family`|Fuente del texto|
|`font-size`|Tamaño de la fuente|
|`font-style`|Normal, cursiva, etc.|
|`font-weight`|Negrita, normal, etc.|
|`line-height`|Altura de línea|

```css
div {
  color: blue;
  font-family: Arial, sans-serif;
}

p {
  /* automáticamente hereda color y fuente del div */
}
```

👉 Todos los `<p>` dentro del `<div>` tendrán texto azul y fuente Arial.

---

## 🔹 Propiedades que **no se heredan** automáticamente

- `margin`, `padding`, `border`
- `width`, `height`, `background`, `display`

Si querés que un hijo las “herede”, hay que usar explícitamente:

```css
.child {
  background: inherit; /* toma el background del padre */
}
```

---

## 🔹 La palabra clave `inherit`

- Se usa para forzar que un elemento **herede** un valor del padre.

```css
h1 {
  color: red;
}

span {
  color: inherit; /* el span tomará el color rojo del h1 padre */
}
```

- También existen **`initial`** (restablece a valor por defecto del navegador) y **`unset`** (combina `inherit` o `initial` según la propiedad).

---

### 🔹 Resumen rápido

1. La **herencia automática** solo aplica a ciertas propiedades, sobre todo de **tipografía y color**.
2. Para otras propiedades se usa `inherit`.
3. Herencia es útil para **mantener consistencia** y no repetir estilos.
