```css
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

es una forma **responsiva** de definir columnas en **CSS Grid**.  
Te explico cada parte:

---

### 🔹 `grid-template-columns`

Define **cómo se reparten las columnas** en el grid.  
Ejemplo simple:

```css
grid-template-columns: 200px 200px 200px;
```

👉 crea 3 columnas fijas de 200px.

---

### 🔹 `repeat()`

Sirve para **repetir un patrón de columnas** sin escribirlo muchas veces.  
Ejemplo:

```css
grid-template-columns: repeat(3, 200px);
```

👉 es lo mismo que `200px 200px 200px`.

---

### 🔹 `minmax(200px, 1fr)`

Esto crea una columna que:

- mide **al menos 200px**
    
- puede crecer hasta ocupar **1 fracción disponible**.
    

👉 Así las columnas no se achican demasiado en pantallas chicas, pero en pantallas grandes se expanden.

---

### 🔹 `auto-fit`

Le dice al grid:  
👉 “mete tantas columnas como quepan en el espacio disponible, y ajusta automáticamente la cantidad”.

---

### 🔹 Resultado final

```css
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

🔸 Hace que las columnas se creen solas.  
🔸 Cada columna tendrá mínimo 200px.  
🔸 Si sobra espacio, las columnas se expanden (`1fr`).  
🔸 En pantallas chicas, el número de columnas se reduce para que no se rompa el diseño.

---

📌 Ejemplo práctico:

```html
<div class="grid">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
  <div>Item 5</div>
</div>
```

```css
.grid {
  display: grid;
  gap: 10px;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}
.grid > div {
  background: lightblue;
  padding: 20px;
  text-align: center;
}
```

👉 En una pantalla grande, tal vez se vean 4 columnas.  
👉 En una tablet, 2 columnas.  
👉 En un celular, 1 columna.
