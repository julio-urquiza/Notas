## 🔹 1. Usando `repeat` con `auto-fit` y `minmax()`

Esta es la forma más moderna y sencilla de hacer un grid que **se adapte automáticamente** al ancho disponible.

```css
.container {
  display: grid;
  gap: 10px;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}
```

### Explicación:

- `repeat(auto-fit, ...)` → crea tantas columnas como quepan en el contenedor.
- `minmax(200px, 1fr)` → cada columna tendrá mínimo 200px y máximo 1 fracción del espacio disponible.
- Resultado:
    - Pantallas grandes → más columnas
    - Pantallas pequeñas → menos columnas, se ajustan automáticamente

## 🔹 2. Usando Media Queries

Si querés controlar **exactamente cuántas columnas** se muestran según el ancho, podés combinar grid con media queries:

```css
.container {
  display: grid;
  gap: 10px;
  grid-template-columns: repeat(4, 1fr); /* default 4 columnas */
}

@media (max-width: 1024px) {
  .container {
    grid-template-columns: repeat(3, 1fr); /* 3 columnas */
  }
}

@media (max-width: 768px) {
  .container {
    grid-template-columns: repeat(2, 1fr); /* 2 columnas */
  }
}

@media (max-width: 480px) {
  .container {
    grid-template-columns: 1fr; /* 1 columna */
  }
}
```

- Control total sobre la **cantidad de columnas** según el dispositivo.

## 🔹 3. Ejemplo completo en HTML + CSS

```html
<div class="container">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
</div>
```

```css
.container {
  display: grid;
  gap: 10px;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
}

.container > div {
  background: lightblue;
  padding: 20px;
  text-align: center;
}
```

- Resultado:
    - Pantalla grande → varias columnas
    - Pantalla pequeña → columnas se reducen automáticamente

---

✅ **Resumen rápido:**

1. `repeat(auto-fit, minmax())` → grid responsivo automático.
2. Media queries → control total sobre cuántas columnas según ancho.
3. Combinar ambas técnicas → máxima flexibilidad.
