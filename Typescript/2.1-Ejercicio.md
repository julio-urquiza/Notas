## Parte B – Union types + control de flujo

Tu función:

```ts
function printId(id: number | string) {
  if (typeof id === "string") {
    console.log(id.toUpperCase())
  } else if (typeof id === "number") {
    console.log(id.toFixed(2))
  }
}
```

### Evaluación

✔️ Union type bien definido  
✔️ Narrowing correcto  
✔️ Uso correcto de APIs (`toUpperCase`, `toFixed`)  
✔️ Control explícito de ambos casos

💡 **Detalle de mejora (opcional, nivel senior)**  
El `else if` no es estrictamente necesario:

```ts
function printId(id: number | string) {
  if (typeof id === "string") {
    console.log(id.toUpperCase())
  } else {
    console.log(id.toFixed(2))
  }
}
```

TypeScript ya sabe que si no es string, **solo puede ser number**.

No es un error, es **una optimización conceptual**.
