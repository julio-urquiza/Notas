## Micro-mejoras (nivel profesional)

No son obligatorias, pero son buenas prácticas.

### 1. Marcar `execute` como `async` (estilo)

```ts
class GetUserService extends BaseService<User> {
    async execute(): Promise<User | null> {
        return { id: 1, name: "John Doe" };
    }
}
```

Más legible y consistente con servicios reales.

---

### 2. `readonly` en el modelo

```ts
interface User {
    readonly id: number;
    name: string;
}
```

IDs no deberían mutar.

---

### 3. Separar dominio de infraestructura (conceptual)

En proyectos reales:

- `User` vive en `domain`
    
- `GetUserService` vive en `application`
    

Tu diseño ya va en esa dirección.
