## 1. `first`

```ts
function first<T>(items: T[]): T | undefined {
    return items[0];
}
```

### Análisis

- `items: T[]`
    
    - **TIPO (TypeScript)**: array de elementos del tipo `T`
        
- `items[0]`
    
    - **RESULTADO (runtime)**: el primer elemento del array **o `undefined`** si está vacío
        
- Retorno `T | undefined`
    
    - **TIPO (TypeScript)**: correcto, refleja exactamente el comportamiento real
        

### Ejemplo

```ts
first([1, 2, 3]);
// RESULTADO (runtime): 1
// TIPO (TypeScript): number | undefined

first([]);
// RESULTADO (runtime): undefined
// TIPO (TypeScript): undefined
```

✅ **Correcto y bien tipado**

## 2. `merge`

```ts
function merge<T, U>(a: T, b: U): T & U {
    return { ...a, ...b };
}
```

### Análisis

- `T & U`
    
    - **TIPO (TypeScript)**: intersección → el resultado tiene **todas las propiedades de `T` y `U`**
        
- `{ ...a, ...b }`
    
    - **RESULTADO (runtime)**: un nuevo objeto con las propiedades de ambos
        

### Ejemplo

```ts
const merged = merge(
  { id: 1 },
  { name: "Ana" }
);
```

- **RESULTADO (runtime)**:
    

```ts
{ id: 1, name: "Ana" }
```

- **TIPO (TypeScript)**:
    

```ts
{ id: number } & { name: string }
```

⚠️ Nota importante (nivel industria):

Si `a` y `b` tienen la **misma propiedad**, TypeScript **no detecta sobrescritura**:

```ts
merge({ id: 1 }, { id: "x" });
// RESULTADO (runtime): { id: "x" }
// TIPO (TypeScript): { id: number } & { id: string } ❌
```

Esto es una **limitación conocida**, no un error tuyo.

## 3. `pluck`

```ts
function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
    return items.map(item => item[key]);
}
```

Esta es la más importante del ejercicio.

### Análisis por partes

- `K extends keyof T`
    
    - **TIPO (TypeScript)**: `key` solo puede ser una clave válida de `T`
        
- `item[key]`
    
    - **RESULTADO (runtime)**: el valor de esa propiedad en cada objeto
        
- `T[K][]`
    
    - **TIPO (TypeScript)**: array del tipo exacto de esa propiedad
        

---

### Ejemplo claro

```ts
const users = [
  { id: 1, name: "Ana" },
  { id: 2, name: "Juan" }
];

const ids = pluck(users, "id");
```

- **RESULTADO (runtime)**:
    

```ts
[1, 2]
```

- **TIPO (TypeScript)**:
    

```ts
number[]
```

---

```ts
const names = pluck(users, "name");
```

- **RESULTADO (runtime)**:
    

```ts
["Ana", "Juan"]
```

- **TIPO (TypeScript)**:
    

```ts
string[]
```

❌ Error correctamente bloqueado:

```ts
pluck(users, "age");
// ERROR (TypeScript)
```
