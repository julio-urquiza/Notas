## El código

```ts
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

---

## Qué significa cada parte (clave)

### 1. `T`

```ts
<T>
```

Representa **el tipo completo del objeto** que pasás.

Ejemplo:

```ts
const user = {
  id: 1,
  name: "Ana"
};
```

Acá:

```ts
T = {
  id: number;
  name: string;
}
```

---

### 2. `keyof T`

```ts
keyof T
```

Significa:

> “unión de todas las claves de T”

Para `user`:

```ts
keyof T = "id" | "name"
```

---

### 3. `K extends keyof T`

```ts
K extends keyof T
```

Se lee así:

> “K solo puede ser una clave válida de T”

Esto evita errores como:

```ts
getProperty(user, "age"); // ❌
```

---

### 4. Tipo de retorno: `T[K]`

Esta es la parte más importante.

```ts
T[K]
```

Significa:

> “el tipo de la propiedad K dentro de T”

---

## Ejemplo concreto (clave para entender)

```ts
const user = {
  id: 1,
  name: "Ana"
};
```

### Caso 1

```ts
getProperty(user, "id");
```

Inferencias:

```ts
T = { id: number; name: string }
K = "id"
T[K] = number
```

👉 **Devuelve `number`**

---

### Caso 2

```ts
getProperty(user, "name");
```

Inferencias:

```ts
K = "name"
T[K] = string
```

👉 **Devuelve `string`**

---

## NO devuelve el objeto

Esto **no** pasa:

```ts
getProperty(user, "id"); // ❌ no devuelve { id: 1, name: "Ana" }
```

Devuelve solo:

```ts
1
```

con tipo `number`.

---

## Comparación sin generics (para ver el valor real)

❌ Versión mala:

```ts
function getProperty(obj: any, key: string): any {
  return obj[key];
}
```

Problemas:

- Podés pasar cualquier clave
    
- Siempre devuelve `any`
    
- Sin autocompletado
    
- Errores en runtime
    

---

## Versión con generics + keyof (industria)

```ts
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K]
```

Beneficios:

- Solo claves válidas
    
- Tipo exacto de retorno
    
- Autocompletado
    
- Seguridad en compilación
    

---

## Analogía simple

Pensalo así:

> “Decime qué objeto es (`T`)  
> y qué propiedad válida querés (`K`)  
> y yo te devuelvo **el valor**, con **su tipo exacto**”

---

## Mini ejercicio mental

```ts
const product = {
  price: 100,
  title: "Libro",
  available: true
};
```

¿Qué tipos devuelve?

```ts
getProperty(product, "price");      // ?
getProperty(product, "title");      // ?
getProperty(product, "available");  // ?
```

Respuesta:

- `number`
    
- `string`
    
- `boolean`
