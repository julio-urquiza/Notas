
# Curso Profesional de TypeScript (desde JS a TS avanzado)

**Duración sugerida:** 4 a 6 semanas  
**Nivel:** Intermedio → Avanzado  
**Prerrequisitos:** JS moderno (ES6+), POO, módulos, async/await

---

## MÓDULO 1 – Fundamentos reales de TypeScript (lo que JS no te da)

### Objetivo

Entender **qué problemas soluciona TS** y cómo se integra sin fricción con JavaScript.

### Contenidos

- ¿Qué es TypeScript realmente? (superset + type checker)
    
- TypeScript ≠ JavaScript con tipos
    
- Compilación: `tsc` → JavaScript
    
- `tsconfig.json` (clave en proyectos reales)
    
- `strict: true` y por qué **SIEMPRE** usarlo
    

### Práctica

```ts
let age: number = 30;
let name: string = "Julio";
let isActive: boolean = true;
```

Errores comunes:

```ts
let total: number = "100"; // Error de compilación
```

## MÓDULO 2 – Tipos primitivos, inferencia y buenas prácticas

### Objetivo

Aprovechar la **inferencia de tipos** y evitar el “tipado innecesario”.

### Contenidos

- Tipos primitivos
    
- Inferencia automática
    
- `any` (cuándo NO usarlo)
    
- `unknown` vs `any`
    
- `void`, `never`
    

### Clave profesional

```ts
let count = 10; // inferido como number (bien)
```

Mal uso:

```ts
let data: any; // perdiste TypeScript
```

Correcto:

```ts
let data: unknown;
```

## MÓDULO 3 – Objetos, interfaces y type aliases

### Objetivo

Modelar **dominio de negocio**, no solo variables.

### Contenidos

- Tipado de objetos
    
- `interface` vs `type`
    
- Propiedades opcionales
    
- `readonly`
    
- Extensión y composición
    

### Ejemplo real

```ts
interface User {
  id: string;
  email: string;
  role: "ADMIN" | "USER";
  isActive?: boolean;
}
```

Extensión:

```ts
interface Admin extends User {
  permissions: string[];
}
```

Evitar bugs en **params, retornos y async**.

### Contenidos

- Tipos de retorno
    
- Funciones async
    
- Overloads
    
- Callbacks tipados

```ts
function calculateTotal(price: number, tax: number): number {
  return price + price * tax;
}
```

Async:

```ts
async function getUser(id: string): Promise<User> {
  // ...
}
```

### Objetivo

Tipar estructuras comunes en frontend y backend.

### Contenidos

- Tuples

## MÓDULO 6 – Clases y POO en TypeScript (nivel industria)

### Objetivo

Usar TS para **POO real**, no decorativa.

### Contenidos

- Clases tipadas
    
- Modificadores: `public`, `private`, `protected`
    
- `readonly`
    
- Implementación de interfaces
    
- Abstract classes
    

### Ejemplo

```ts
interface Repository<T> {
  findById(id: string): Promise<T | null>;
}

class UserRepository implements Repository<User> {
  async findById(id: string): Promise<User | null> {
    return null;
  }
}
```

## MÓDULO 7 – Generics (uno de los mayores beneficios de TS)

### Objetivo

Crear código **reutilizable y seguro**.

### Contenidos

- Generics en funciones
    
- Generics en interfaces y clases
    
- Constraints (`extends`)
    

### Ejemplo

```ts
function wrap<T>(value: T): T[] {
  return [value];
}
```

Con constraints:

```ts
function getId<T extends { id: string }>(obj: T): string {
  return obj.id;
}
```

## MÓDULO 8 – Union types, narrowing y type guards

### Objetivo

Controlar flujos complejos sin `if` caóticos.

### Contenidos

- Union types
    
- Narrowing
    
- `in`, `typeof`, `instanceof`
    
- Custom type guards
    

### Ejemplo

```ts
type ApiResponse = User | Error;

function handleResponse(res: ApiResponse) {
  if ("email" in res) {
    console.log(res.email);
  }
}
```

## MÓDULO 12 – Buenas prácticas y anti-patrones

### Claves profesionales

- Evitar `any`
    
- No sobre-tipar
