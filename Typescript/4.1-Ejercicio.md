function calculateDiscount(price: number, discount: number): number {

## 3. `fetchProduct` – Acá está el punto clave

Tu implementación:

```ts
async function fetchProduct(id: string): Promise<Product | null> {
  try {
    const response = await fetch(`API_URL/products/${id}`)
    return await response.json()
  }
  catch (error) {
    console.error(error)
  }
}
```

### Problemas reales (importantes)

1. ❌ La función **no retorna siempre** `Product | null`
    
2. ❌ `response.json()` devuelve `any`
    
3. ❌ No validás si el response es OK
    
4. ❌ No existe un “cast” seguro automático
    

TypeScript **no puede confiar** en una API externa.

---

## Concepto CLAVE (esto responde tu duda)

> **En TypeScript NO se “castea” una API a un tipo.  
> Se valida o se asume bajo contrato.**

Hay **3 niveles** de manejo, de junior → senior.

---

## NIVEL 1 – Type assertion (simple, pero peligrosa)

```ts
const data = await response.json() as Product;
return data;
```

✔️ Compila  
❌ No valida nada  
❌ Si la API cambia, rompés en runtime

👉 **NO recomendado para datos externos**.

---

## NIVEL 2 – Validación mínima (recomendado)

```ts
async function fetchProduct(id: string): Promise<Product | null> {
  try {
    const response = await fetch(`API_URL/products/${id}`);

    if (!response.ok) {
      return null;
    }

    const data: unknown = await response.json();

    if (
      typeof data === "object" &&
      data !== null &&
      "id" in data &&
      "name" in data &&
      "price" in data
    ) {
      return data as Product;
    }

    return null;
  } catch (error) {
    console.error(error);
    return null;
  }
}
```

✔️ Usás `unknown`  
✔️ Validás forma mínima  
✔️ TS queda conforme  
✔️ Mucho más seguro

Esto es **muy industria real**.

---

## NIVEL 3 – Type guard (nivel alto)

```ts
function isProduct(data: unknown): data is Product {
  return (
    typeof data === "object" &&
    data !== null &&
    "id" in data &&
    "name" in data &&
    "price" in data
  );
}
```

Uso:

```ts
async function fetchProduct(id: string): Promise<Product | null> {
  try {
    const response = await fetch(`API_URL/products/${id}`);
    if (!response.ok) return null;

    const data: unknown = await response.json();

    if (isProduct(data)) {
      return data;
    }

    return null;
  } catch (error) {
    console.error(error);
    return null;
  }
}
```

📌 **Este es el patrón correcto**.

---

## Por qué esto es importante (concepto clave)

TypeScript:

- **NO valida runtime**
    
- **NO confía en inputs externos**
    
- Solo protege lo que vos modelás
    

Por eso:

- APIs
    
- DBs
    
- JSON
    
- Inputs de usuario
    

👉 **Siempre entran como `unknown`**.
