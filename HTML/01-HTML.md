HTML significa **HyperText Markup Language** (Lenguaje de Marcado de Hipertexto).  
Es el **lenguaje estándar para crear páginas web**.

👉 Algunos puntos clave:

- **Lenguaje de marcado**: No es un lenguaje de programación, sino un sistema de etiquetas (tags) que definen la estructura y el contenido de una página.
- **Estructura**: Permite organizar texto, imágenes, enlaces, videos, formularios y otros elementos.
- **Hipertexto**: Hace posible enlazar una página con otra mediante enlaces (`<a>`).
- **Base de la web**: Los navegadores (Chrome, Firefox, Edge, etc.) interpretan el código HTML y muestran la página al usuario.

🔹 Ejemplo básico de HTML:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola, mundo</h1>
  <p>Este es un párrafo en HTML.</p>
  <a href="https://www.google.com">Ir a Google</a>
</body>
</html>
```

En este ejemplo:

- `<h1>` define un título.
- `<p>` define un párrafo.
- `<a>` define un enlace.
