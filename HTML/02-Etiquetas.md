HTML tiene **más de 100 etiquetas** oficiales (dependiendo de la versión y del estándar W3C/WHATWG). 
No siempre se usan todas, porque algunas están **obsoletas** y otras son muy específicas.

Para que no sea un listado caótico, te las muestro organizadas por categorías principales 👇

---

## 📌 Estructura básica del documento

- `<!DOCTYPE>` → Define el tipo de documento.
- `<html>` → Raíz del documento.
- `<head>` → Contiene metadatos.
- `<body>` → Contiene el contenido visible.

---

## 📌 Metadatos

- `<title>` → Título de la página.
- `<meta>` → Información adicional (charset, SEO, responsive, etc.).
- `<link>` → Enlaces a recursos externos (CSS, íconos).
- `<style>` → CSS embebido.
- `<base>` → URL base para los enlaces.

---

## 📌 Secciones y estructura

- `<header>` → Encabezado de la página o sección.
- `<nav>` → Menú de navegación.
- `<main>` → Contenido principal.
- `<section>` → Sección temática.
- `<article>` → Contenido independiente.
- `<aside>` → Barra lateral, contenido complementario.
- `<footer>` → Pie de página.
- `<div>` → Contenedor genérico.

---

## 📌 Texto y formato

- `<h1>` a `<h6>` → Títulos.
- `<p>` → Párrafo.
- `<br>` → Salto de línea.
- `<hr>` → Línea de separación.
- `<span>` → Contenedor en línea.
- `<strong>` → Texto importante (negrita semántica).
- `<em>` → Énfasis (cursiva semántica).
- `<b>`, `<i>`, `<u>` → Negrita, cursiva y subrayado (no semánticos).
- `<mark>` → Resaltado.
- `<small>` → Texto pequeño.
- `<sup>` / `<sub>` → Superíndice / subíndice.
- `<blockquote>` → Cita en bloque.
- `<q>` → Cita en línea.
- `<code>` → Código en línea.
- `<pre>` → Texto preformateado.
- `<abbr>` → Abreviatura.
- `<cite>` → Referencia a un autor/obra.
- `<dfn>` → Definición de un término.
- `<kbd>` → Entrada de teclado.
- `<samp>` → Salida de un programa.
- `<var>` → Variable.

---

## 📌 Enlaces e interactividad

- `<a>` → Hipervínculo.
- `<button>` → Botón.

---

## 📌 Listas

- `<ul>` → Lista no ordenada.
- `<ol>` → Lista ordenada.
- `<li>` → Elemento de lista.
- `<dl>` → Lista de definiciones.
- `<dt>` → Término de definición.
- `<dd>` → Descripción del término.

---

## 📌 Multimedia

- `<img>` → Imagen.
- `<audio>` → Audio.
- `<video>` → Video.
- `<source>` → Fuente para `<audio>` o `<video>`.
- `<track>` → Subtítulos de video.
- `<canvas>` → Dibujo en 2D/3D con JS.
- `<svg>` → Gráficos vectoriales.
- `<map>` / `<area>` → Mapas de imágenes.
- `<figure>` → Elemento gráfico con leyenda.
- `<figcaption>` → Leyenda de la figura.
- `<picture>` → Imagen adaptable.

---

## 📌 Formularios

- `<form>` → Formulario.
- `<input>` → Campo de entrada.
- `<textarea>` → Área de texto.
- `<select>` → Lista desplegable.
- `<option>` → Opción en `<select>`.
- `<optgroup>` → Grupo de opciones.
- `<label>` → Etiqueta para campo.
- `<fieldset>` → Grupo de campos.
- `<legend>` → Título de un grupo.
- `<button>` → Botón de formulario.
- `<datalist>` → Lista de sugerencias.
- `<output>` → Resultado calculado.

---

## 📌 Tablas

- `<table>` → Tabla.
- `<caption>` → Título de tabla.
- `<thead>` → Encabezado.
- `<tbody>` → Cuerpo.
- `<tfoot>` → Pie.
- `<tr>` → Fila.
- `<th>` → Celda de encabezado.
- `<td>` → Celda de datos.
- `<colgroup>` → Grupo de columnas.
- `<col>` → Define una columna.

---

## 📌 Contenido interactivo y embebido

- `<iframe>` → Incrustar otra página.
- `<embed>` → Contenido externo.
- `<object>` → Objeto externo.
- `<param>` → Parámetro de objeto.

---

## 📌 Scripts

- `<script>` → Código JavaScript.
- `<noscript>` → Contenido alternativo si JS está deshabilitado.

---

## 📌 Etiquetas obsoletas (ya no recomendadas 🚫)

- `<center>`, `<font>`, `<marquee>`, `<big>`, `<tt>` y varias más.  
    Hoy en día se reemplazan con **CSS** o etiquetas semánticas.
