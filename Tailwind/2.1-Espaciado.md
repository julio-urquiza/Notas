## 🧩 **Módulo 5: Espaciado (Margin, Padding, Gap, Space)**

El espaciado es clave para crear diseños limpios y con buena jerarquía visual.  
En Tailwind, el espaciado se controla principalmente con **m**, **p**, **gap**, y **space**.

---

### 🟦 1. **Margin (`m`, `mt`, `mb`, `ml`, `mr`, `mx`, `my`)**

**Sintaxis:**

```html
m-4   /* margen en todos los lados */
mt-2  /* margen arriba */
mb-8  /* margen abajo */
mx-6  /* margen horizontal (izq + der) */
my-10 /* margen vertical (arriba + abajo) */
```

**Ejemplo:**

```html
<div class="m-4 bg-blue-200">Margen en todos lados</div>
<div class="mt-10 bg-green-200">Margen superior grande</div>
```

📏 Las unidades siguen la **escala de Tailwind**, por defecto:

```
m-1 → 0.25rem (4px)
m-2 → 0.5rem (8px)
m-4 → 1rem (16px)
m-8 → 2rem (32px)
```

👉 También podés usar valores arbitrarios:

```html
<div class="m-[30px]">Margen personalizado</div>
```

---

### 🟩 2. **Padding (`p`, `pt`, `pb`, `pl`, `pr`, `px`, `py`)**

**Sintaxis:**

```html
p-4   /* padding en todos los lados */
px-8  /* padding horizontal */
py-2  /* padding vertical */
pt-10 /* padding superior */
```

**Ejemplo:**

```html
<button class="px-6 py-2 bg-blue-500 text-white rounded-lg">
  Botón con padding
</button>
```

---

### 🟧 3. **Gap (en Flex y Grid)**

Controla el espacio entre los elementos **internos** de un contenedor con `flex` o `grid`.

**Ejemplo:**

```html
<div class="flex gap-4">
  <div class="bg-red-300 p-4">1</div>
  <div class="bg-red-300 p-4">2</div>
  <div class="bg-red-300 p-4">3</div>
</div>
```

💡 `gap` reemplaza la necesidad de poner márgenes manualmente en los hijos.

---

### 🟨 4. **Space Between (solo en flex o grid)**

Agrega espacio entre elementos **adyacentes**, sin afectar los bordes externos.

**Ejemplo:**

```html
<div class="flex space-x-4">
  <div class="bg-purple-300 p-2">A</div>
  <div class="bg-purple-300 p-2">B</div>
  <div class="bg-purple-300 p-2">C</div>
</div>
```

📘 Variantes:

- `space-x-*` → espacio horizontal
    
- `space-y-*` → espacio vertical
    

---

### 🧠 **Resumen**

|Propiedad|Qué hace|Ejemplo|
|---|---|---|
|`m-*`|Margen externo|`m-4`, `mx-2`, `mt-8`|
|`p-*`|Relleno interno|`p-4`, `px-8`, `py-2`|
|`gap-*`|Espacio entre hijos|`gap-4`|
|`space-x-*`, `space-y-*`|Espacio dinámico entre hijos|`space-y-6`|
