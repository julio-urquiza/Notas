Tailwind se puede instalar de varias formas, depende de cómo estés trabajando tu proyecto (con HTML simple, con frameworks como React/Vue, o usando un bundler como Vite/Webpack).  
Te muestro las formas más comunes:

---

## 🔹 1. Usarlo con un `<link>` (la forma más rápida)

Si solo quieres probarlo sin instalar nada:

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Tailwind prueba</title>
    <script src="https://cdn.tailwindcss.com"></script>
  </head>
  <body class="bg-gray-100 p-10">
    <h1 class="text-3xl font-bold text-blue-600">Hola Tailwind</h1>
  </body>
</html>
```

👉 Ideal para tests rápidos o proyectos chicos.

---

## 🔹 2. Instalación con **npm** (recomendada para proyectos reales)

https://tailwindcss.com/docs/installation/tailwind-cli
The simplest and fastest way to get up and running with Tailwind CSS from scratch is with the Tailwind CLI tool. The CLI is also available as a [standalone executable](https://github.com/tailwindlabs/tailwindcss/releases/latest) if you want to use it without installing Node.js.

- ### Install Tailwind CSS

Install `tailwindcss` and `@tailwindcss/cli` via npm.

``` terminal
npm install tailwindcss @tailwindcss/cli
```

- ### Import Tailwind in your CSS

Add the `@import "tailwindcss";` import to your main CSS file.

src/input.css
``` css 
@import "tailwindcss";
```

- ### Start the Tailwind CLI build process

Run the CLI tool to scan your source files for classes and build your CSS.

``` terminal
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

- ### Start using Tailwind in your HTML

Add your compiled CSS file to the `<head>` and start using Tailwind’s utility classes to style your content.

src/index.html

``` html
<!doctype html>
<html>
	<head>  
		<meta charset="UTF-8">  
		<meta name="viewport" content="width=device-width, initial-scale=1.0">  
		<link href="./output.css" rel="stylesheet">
	</head>
	<body>
		<h1 class="text-3xl font-bold underline">    Hello world!  </h1>
	</body>
  </html>
```

## 🔹 3. Con frameworks (ejemplo React + Vite)

Si usas un framework moderno:

```bash
npm create vite@latest mi-proyecto
cd mi-proyecto
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Luego sigues los pasos de configuración como en el punto 2.
