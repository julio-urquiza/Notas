## 🔹 1. Instalar dependencias

Dentro de tu proyecto NestJS:

```bash
npm install @nestjs/mongoose mongoose
```

Esto instala:

- `mongoose`: librería para trabajar con MongoDB.
- `@nestjs/mongoose`: integración oficial de Nest con Mongoose.

---

## 🔹 2. Conectar NestJS con MongoDB

En el archivo `app.module.ts`, importá `MongooseModule` y configurá la conexión:

```ts
import { Module } from '@nestjs/common';
import { MongooseModule } from '@nestjs/mongoose';
import { UsersModule } from './users/users.module';

@Module({
  imports: [
    MongooseModule.forRoot('mongodb://localhost:27017/mi_base'), // URL de conexión
    UsersModule,
  ],
})
export class AppModule {}
```

⚠️ Importante: asegurate de tener **MongoDB corriendo en tu máquina** (por defecto en `mongodb://localhost:27017`).

---

## 🔹 3. Crear un esquema (modelo de datos)

En tu módulo de usuarios (`users`), definí un esquema:

📄 `users/schemas/user.schema.ts`

```ts
import { Prop, Schema, SchemaFactory } from '@nestjs/mongoose';
import { Document } from 'mongoose';

export type UserDocument = User & Document;

@Schema()
export class User {
  @Prop({ required: true })
  name: string;

  @Prop({ required: true, unique: true })
  email: string;
}

export const UserSchema = SchemaFactory.createForClass(User);
```

---

## 🔹 4. Importar el esquema en el módulo

📄 `users/users.module.ts`

```ts
import { Module } from '@nestjs/common';
import { MongooseModule } from '@nestjs/mongoose';
import { UsersService } from './users.service';
import { UsersController } from './users.controller';
import { User, UserSchema } from './schemas/user.schema';

@Module({
  imports: [
    MongooseModule.forFeature([{ name: User.name, schema: UserSchema }]),
  ],
  controllers: [UsersController],
  providers: [UsersService],
})
export class UsersModule {}
```

---

## 🔹 5. Usar el modelo en el servicio

📄 `users/users.service.ts`

```ts
import { Injectable } from '@nestjs/common';
import { InjectModel } from '@nestjs/mongoose';
import { Model } from 'mongoose';
import { User, UserDocument } from './schemas/user.schema';

@Injectable()
export class UsersService {
  constructor(@InjectModel(User.name) private userModel: Model<UserDocument>) {}

  async findAll(): Promise<User[]> {
    return this.userModel.find().exec();
  }

  async findOne(id: string): Promise<User> {
    return this.userModel.findById(id).exec();
  }

  async create(data: { name: string; email: string }): Promise<User> {
    const newUser = new this.userModel(data);
    return newUser.save();
  }
}
```

---

## 🔹 6. Probar la API

Si levantás el servidor con:

```bash
npm run start:dev
```

Podés usar las rutas que ya tenías (`GET /users`, `POST /users`, etc.), pero ahora los datos se van a **guardar en MongoDB**.
