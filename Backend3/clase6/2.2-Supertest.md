**Supertest** es una librería de Node.js que se usa para **testear APIs HTTP** de forma sencilla.  
Funciona encima de **Superagent** (un cliente HTTP) y se integra muy bien con frameworks como **Express**.

👉 La ventaja es que no necesitás levantar un servidor real en un puerto para testear tu API: podés usar directamente tu aplicación de Express en memoria.

---

### Instalación

```bash
npm install --save-dev supertest mocha
```

---

### Ejemplo usando **Mocha + Supertest**

Supongamos que tenés un servidor Express (`app.js`):

```js
const express = require("express");
const app = express();

app.get("/saludo", (req, res) => {
  res.status(200).json({ mensaje: "Hola Mundo" });
});

module.exports = app;
```

Y un archivo de test (`test/app.test.js`):

```js
const request = require("supertest");
const app = require("../app"); // tu app de Express
const assert = require("assert");

describe("Pruebas de API con Supertest", function () {
  it("Debería responder con Hola Mundo", function (done) {
    request(app)
      .get("/saludo")
      .expect("Content-Type", /json/)
      .expect(200)
      .end((err, res) => {
        if (err) return done(err);
        assert.strictEqual(res.body.mensaje, "Hola Mundo");
        done();
      });
  });
});
```

---

### Cómo correr las pruebas

En tu `package.json`, añadí:

```json
"scripts": {
  "test": "mocha"
}
```

Y luego ejecutás:

```bash
npm test
```
