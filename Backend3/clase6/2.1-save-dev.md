La opción `--save-dev` en **npm** se usa cuando instalás un paquete que **solo necesitás durante el desarrollo** de tu proyecto, pero **no en producción**.

📌 Ejemplo:

```bash
npm install --save-dev mocha
```

Esto guarda **Mocha** en la sección `"devDependencies"` de tu `package.json`.

---

### Diferencia entre `dependencies` y `devDependencies`:

- **`dependencies`**  
    Son librerías que tu aplicación necesita para **funcionar en producción**.  
    Ejemplo: Express, React, Lodash, etc.
   ```json
    "dependencies": {
      "express": "^4.18.0"
    }
    ```
- **`devDependencies`**  
    Son librerías que solo usás en **desarrollo, testing o build**, pero no cuando tu app ya está en ejecución en producción.  
    Ejemplo: Mocha, Chai, ESLint, Webpack, Babel.
   ```json
    "devDependencies": {
      "mocha": "^10.0.0",
      "chai": "^4.3.0"
    }
    ```

---

🔎 ¿Por qué es útil?  
Porque cuando desplegás tu aplicación (ej: en un servidor o Docker), podés instalar solo las `dependencies` necesarias para que corra, con:

```bash
npm install --production
```

Esto **ignora las `devDependencies`** y hace que tu app sea más liviana.
