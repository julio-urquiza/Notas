Swagger es un **conjunto de herramientas y especificaciones** que se utiliza para **diseñar, documentar y probar APIs REST** de manera sencilla y estandarizada.

👉 En términos simples: sirve para **describir tu API** (endpoints, parámetros, respuestas, errores, etc.) en un formato legible tanto para humanos como para máquinas.

Actualmente, Swagger forma parte del **ecosistema OpenAPI** (la especificación más usada para describir APIs).

### ¿Qué ofrece Swagger?

1. **Swagger Editor** → permite escribir la documentación de la API en formato YAML o JSON.
2. **Swagger UI** → genera una **interfaz web interactiva** donde puedes probar los endpoints de tu API sin necesidad de usar Postman o cURL.
3. **Swagger Codegen** → genera automáticamente **clientes, servidores y documentación** en múltiples lenguajes a partir de la especificación de la API.

### Ejemplo básico de especificación Swagger (OpenAPI en YAML):

```yaml
openapi: 3.0.0
info:
  title: API de ejemplo
  version: 1.0.0
paths:
  /usuarios:
    get:
      summary: Obtener lista de usuarios
      responses:
        '200':
          description: Lista de usuarios
```

Con esto, Swagger UI te mostrará un botón para **probar el endpoint `/usuarios`** directamente en el navegador. 🚀

---

### 1. Crear proyecto básico

```bash
mkdir api-swagger
cd api-swagger
npm init -y
npm install express swagger-ui-express swagger-jsdoc
```

---

### 2. Crear el servidor con Swagger

Crea un archivo `index.js` con este contenido:

```js
const express = require("express");
const swaggerUi = require("swagger-ui-express");
const swaggerJsdoc = require("swagger-jsdoc");

const app = express();

// Configuración de Swagger
const swaggerOptions = {
  definition: {
    openapi: "3.0.0",
    info: {
      title: "API de ejemplo con Swagger",
      version: "1.0.0",
      description: "Documentación generada con Swagger para Express.js",
    },
    servers: [
      {
        url: "http://localhost:3000",
      },
    ],
  },
  apis: ["./index.js"], // Archivos donde estará la documentación
};

const swaggerDocs = swaggerJsdoc(swaggerOptions);
app.use("/api-docs", swaggerUi.serve, swaggerUi.setup(swaggerDocs));

/**
 * @swagger
 * /usuarios:
 *   get:
 *     summary: Obtener todos los usuarios
 *     responses:
 *       200:
 *         description: Lista de usuarios
 */
app.get("/usuarios", (req, res) => {
  res.json([
    { id: 1, nombre: "Juan" },
    { id: 2, nombre: "Ana" },
  ]);
});

app.listen(3000, () => {
  console.log("Servidor corriendo en http://localhost:3000");
  console.log("Documentación en http://localhost:3000/api-docs");
});
```

---

### 3. Probar la API

1. Levanta el servidor:
    
    ```bash
    node index.js
    ```
    
2. Abre en el navegador:  
    👉 `http://localhost:3000/api-docs`
    

Ahí verás la **interfaz interactiva de Swagger** donde podés probar el endpoint `/usuarios`. 🎉
