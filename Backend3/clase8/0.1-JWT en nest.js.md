## 🔹 1. Instalar dependencias

Ejecutá en tu proyecto NestJS:

```bash
npm install @nestjs/jwt passport-jwt
npm install passport @nestjs/passport
```

- `@nestjs/jwt` → integración de JWT en Nest.
- `passport-jwt` → estrategia JWT para Passport.
- `passport` y `@nestjs/passport` → Nest usa Passport para manejar estrategias de autenticación.

---

## 🔹 2. Crear el módulo de autenticación

Generalmente se hace un módulo `auth`.

```bash
nest g module auth
nest g service auth
nest g controller auth
```

---

## 🔹 3. Configurar `JwtModule`

En `auth.module.ts`:

```ts
import { Module } from '@nestjs/common';
import { JwtModule } from '@nestjs/jwt';
import { PassportModule } from '@nestjs/passport';
import { AuthService } from './auth.service';
import { AuthController } from './auth.controller';

@Module({
  imports: [
    PassportModule,
    JwtModule.register({
      secret: 'mi_secreto_super_seguro', // ⚠️ Mejor usar variables de entorno
      signOptions: { expiresIn: '1h' }, // Token válido por 1 hora
    }),
  ],
  controllers: [AuthController],
  providers: [AuthService],
  exports: [AuthService], // para usarlo en otros módulos
})
export class AuthModule {}
```

## 🔹 4. Generar un JWT en el servicio

En `auth.service.ts`:

```ts
import { Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';

@Injectable()
export class AuthService {
  constructor(private jwtService: JwtService) {}

  async login(user: any) {
    const payload = { username: user.username, sub: user.userId };
    return {
      access_token: this.jwtService.sign(payload),
    };
  }
}
```

---

## 🔹 5. Usar el login en el controlador

En `auth.controller.ts`:

```ts
import { Controller, Post, Body } from '@nestjs/common';
import { AuthService } from './auth.service';

@Controller('auth')
export class AuthController {
  constructor(private authService: AuthService) {}

  @Post('login')
  async login(@Body() user: { username: string; userId: number }) {
    return this.authService.login(user);
  }
}
```

## 🔹 6. Proteger rutas con JWT (Passport Strategy)

Creamos un `jwt.strategy.ts` en `auth`:

```ts
import { Injectable } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      ignoreExpiration: false,
      secretOrKey: 'mi_secreto_super_seguro', // usar env
    });
  }

  async validate(payload: any) {
    return { userId: payload.sub, username: payload.username };
  }
}
```

Y lo registramos en `auth.module.ts`:

```ts
import { JwtStrategy } from './jwt.strategy';

@Module({
  imports: [/* ... */],
  providers: [AuthService, JwtStrategy],
})
export class AuthModule {}
```

## 🔹 7. Proteger una ruta

En cualquier controlador:

```ts
import { Controller, Get, UseGuards } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';

@Controller('users')
export class UsersController {
  @Get('profile')
  @UseGuards(AuthGuard('jwt'))
  getProfile() {
    return { message: 'Ruta protegida con JWT' };
  }
}
```

Ahora esa ruta solo responde si mandás un **Bearer Token** válido.
