Docker es una **plataforma que permite crear, ejecutar y distribuir aplicaciones dentro de contenedores**.  
Un _contenedor_ es como una “cajita” que incluye **tu aplicación + todas sus dependencias** (librerías, runtime, configuraciones). Esto garantiza que funcione igual en cualquier máquina.

---

## 🧩 ¿Por qué existe Docker?

Antes era común que una app funcionara en tu PC pero fallara en el servidor porque:

- Tenía otra versión de Node, Python, Java…
- Faltaba una librería
- Cambiaba el sistema operativo

Docker soluciona eso creando un entorno aislado, portátil y reproducible.

---

## 📦 ¿Qué es un contenedor?

Un **contenedor** es:

- Ligero (más liviano que una máquina virtual)
- Rápido de iniciar
- Aislado del sistema host
- Reproducible

Piensalo como:

> “Mi app corre igual en mi máquina, en tu máquina y en producción.”

---

## 🏗️ ¿Qué es una imagen?

Una **imagen de Docker** es una "plantilla congelada".  
Contiene:

- el sistema base (Ubuntu slim, Alpine, etc.)
- tu código
- las dependencias
- instrucciones para ejecutar la app

Los contenedores se crean a partir de una imagen.

---

## 🧱 ¿Qué es un Dockerfile?

Es un archivo que dice **cómo construir una imagen**.

Ejemplo para Node.js:

```dockerfile
FROM node:18
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD ["npm", "start"]
```

---

## 🚀 ¿Para qué se usa Docker?

- Desplegar apps de backend, frontend, bases de datos, microservicios
- Crear entornos iguales para todo el equipo
- Aislar servicios (redis, postgres, mongodb)
- Automatizar despliegues con CI/CD
- Ejecutar apps en cloud o VPS sin problemas de compatibilidad

---

## 🆚 ¿Docker vs máquinas virtuales?

|Docker|Máquina Virtual|
|---|---|
|Usa el kernel del host|Incluye un SO completo|
|Arranca en milisegundos|Arranca en minutos|
|Muy liviano|Pesado|
|Ideal para microservicios|Ideal para entornos totalmente aislados|

---

## 🧪 Ejemplo rápido

Correr una app de Node dentro de Docker:

```bash
docker build -t mi-app .
docker run -p 3000:3000 mi-app
```

# 🚀 2. Probar que funciona

Abrí una terminal y ejecutá:

```bash
docker --version

```

Si ves un mensaje de bienvenida, Docker está funcionando.

# 📦 3. Cómo usar Docker (lo más básico)

## **A) Ejecutar un contenedor ya existente**

Por ejemplo, correr **Nginx**:

```bash
docker run -p 8080:80 nginx
```

Luego abrís en navegador:  
👉 [http://localhost:8080](http://localhost:8080/)

## **B) Ver contenedores en ejecución**

```bash
docker ps
```

## **C) Ver todos los contenedores (incluye apagados)**

```bash
docker ps -a
```

## **D) Apagar un contenedor**

```bash
docker stop <id>
```

## **E) Eliminar un contenedor**

```bash
docker rm <id>
```

---

# 🏗️ 4. Crear tu propia imagen (Dockerfile)

Ejemplo para una app Node.js:

1. Crear archivo `Dockerfile`:

```dockerfile
FROM node:18
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD ["npm", "start"]
EXPOSE 3000
```

2. Construir imagen:

```bash
docker build -t mi-app .
```

3. Ejecutar la app:

```bash
docker run -p 3000:3000 mi-app
```

Entrás a:  
👉 [http://localhost:3000](http://localhost:3000/)

---

# ⚙️ 5. docker-compose (para varios servicios)

Si tu proyecto necesita, por ejemplo, Node + MongoDB:

`docker-compose.yml`:

```yaml
services:
  app:
    build: .
    ports:
      - "3000:3000"
  mongo:
    image: mongo
    ports:
      - "27017:27017"
```

Y lo levantás con:

```bash
docker compose up
```
