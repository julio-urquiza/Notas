Minikube es una **herramienta que te permite crear y ejecutar un clúster de Kubernetes de manera local** en tu computadora. 🚀

En lugar de tener que desplegar Kubernetes en servidores en la nube (como AWS, GCP, Azure) o en infraestructura compleja, **Minikube levanta un clúster de Kubernetes en una sola máquina virtual (o contenedor, dependiendo del driver que uses)**.

---

### 🔑 Características principales:

- **Entorno local de Kubernetes**: ideal para aprender, probar y desarrollar.
- **Multiplataforma**: funciona en Windows, Linux y macOS.
- **Drivers flexibles**: puede usar VirtualBox, Hyper-V, Docker, etc. como backend.
- **Incluye complementos**: como Ingress, Dashboard, LoadBalancer, Metrics Server, etc.
- **Ligero y rápido**: se enfoca en desarrollo y pruebas, no en producción.

---

### 🛠️ ¿Para qué se usa?

- Practicar y aprender Kubernetes sin necesidad de un clúster en la nube.
- Desarrollar y probar aplicaciones que luego se desplegarán en un entorno real de Kubernetes.
- Simular un entorno de múltiples nodos (aunque en realidad corra todo dentro de una misma máquina).

---

### ⚡ Ejemplo básico de uso

1. Instalar Minikube.
2. Iniciar un clúster:
   ```bash
    minikube start
    ```
3. Ver el estado del clúster:
   ```bash
    minikube status
    ```
4. Acceder al dashboard web de Kubernetes:
   ```bash
    minikube dashboard
    ```
5. Detener el clúster:
   ```bash
    minikube stop
    ```

---

👉 En resumen: **Minikube es como un “mini Kubernetes” en tu máquina local, pensado para desarrollo y aprendizaje.**

---

## 🔹 Requisitos previos

1. **Tener instalado Docker Desktop**  
    👉 Si no lo tenés, se descarga desde [Docker Desktop](https://www.docker.com/products/docker-desktop/).
    
2. **Tener kubectl** (el cliente oficial de Kubernetes).
    
    - Si ya instalaste Docker Desktop, viene incluido.
    - Si no, podés instalarlo con:
```powershell
    choco install kubernetes-cli -y
```
1. **Activar la virtualización** en la BIOS (casi siempre ya viene activa si usás Docker).

---

## 🔹 Instalación de Minikube en Windows

### Opción 1: con **Chocolatey** (más simple)

Si tenés Chocolatey instalado, en **PowerShell como Administrador**:
```powershell
choco install minikube -y
```

### Opción 2: descarga manual

1. Bajá el binario desde 👉 [Releases de Minikube](https://github.com/kubernetes/minikube/releases).
2. Copialo a una carpeta en tu PATH (ejemplo: `C:\Program Files\minikube`).
3. Probá que funciona:
   ```powershell
    minikube version
    ``` 

---

## 🔹 Crear tu primer clúster

1. Iniciá Minikube con Docker como driver:
   ```powershell
    minikube start --driver=docker
    ```
2. Verificá el estado:
   ```powershell
    minikube status
    ```
3. Probá el dashboard de Kubernetes:
   ```powershell
    minikube dashboard
    ```

---

## 🔹 Comandos útiles

- **Detener el clúster**:
   ```powershell
    minikube stop
    ```
- **Eliminar el clúster**:
   ```powershell
    minikube delete
    ```
- **Ver IP del clúster**:
   ```powershell
    minikube ip
    ```

---

👉 Con esto ya podés levantar Kubernetes en tu máquina y empezar a probar pods, deployments y servicios.
